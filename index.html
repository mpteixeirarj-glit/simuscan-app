Metodologia

Simule o exame completo, do início ao fim

O fluxo do simulador reproduz cada etapa de uma aquisição real para que a memória muscular seja formada antes do contato com o equipamento.

Passo 1

Login e acesso

Cada usuário tem acesso individual ao ambiente de simulação. Sem compartilhamento de credenciais.

Passo 2

Escolha o sistema

Selecione o equipamento que deseja praticar. Cada sistema tem interface própria e fluxo de trabalho distinto.

Passo 3

Execute o exame

Worklist, protocolo, posicionamento, topograma, aquisição e reconstrução — exatamente como no equipamento real.

Funcionalidades

O que você vai praticar

Módulos desenvolvidos para cobrir cada etapa real de operação de equipamentos de imagem médica.

📋

Worklist de pacientes

Acesse a lista de exames, selecione o paciente e confirme os dados clínicos antes de iniciar o procedimento — o mesmo fluxo do equipamento real.

📐

Seleção de protocolo

Escolha o protocolo correto por região anatômica com parâmetros ajustáveis.

🧍

Posicionamento

Supino, prone, lateral e variações para cada região do corpo.

📡

Topograma (Scout)

Execute o topograma de planejamento e delimite o volume de aquisição.

🖥️

Tela dupla — Console + Viewer

Alterne entre a tela de operação e o visualizador de imagens, simulando um ambiente de dois monitores como no equipamento real.

🔧

Gerenciador de protocolos

Navegue e organize os protocolos disponíveis no sistema.

📊

Calibração diária

Checklist de preparo do equipamento antes do início das atividades.

🔔

Feedback sonoro

Retorno auditivo em ações corretas e incorretas para reforçar o aprendizado.
